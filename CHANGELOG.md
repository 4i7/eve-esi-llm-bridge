# Changelog

## 0.1.0 — 2026-08-02

Initial public-ready reference package.

- self-hosted Vercel/Next.js remote MCP server;
- bring-your-own EVE Developer Application and EVE SSO authorization;
- nested MCP OAuth → EVE SSO PKCE flow;
- stateless DCR and encrypted outer MCP tokens;
- authenticated/public ESI tools and resolver tools;
- OpenAPI/scope capability discovery;
- private-character path binding;
- write actions disabled by default;
- allowlisted prepare → execute write tickets;
- English/Japanese setup documentation;
- generic Agent Skill starter and prompt pack;
- offline browser secret generator;
- policy/crypto unit tests.
